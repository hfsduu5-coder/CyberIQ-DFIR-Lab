# Case Workflow

A production-style training workflow is:

1. Create a case and record the analyst identity in local notes.
2. Add only copies of authorized evidence.
3. Verify the evidence manifest before and after analysis.
4. Record custody actions when evidence changes hands or analytical state changes.
5. Run offline parsers and timeline extraction.
6. Create findings that cite the relevant evidence and describe observations separately from conclusions.
7. Validate the case manifest.
8. Export reports and a dashboard.
9. Close the case only after integrity verification and analyst review.

CyberIQ DFIR Lab does not replace organizational forensic procedures, legal requirements, or specialist forensic suites.
