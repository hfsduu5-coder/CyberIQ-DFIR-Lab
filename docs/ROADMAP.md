# Roadmap

## v1.x hardening
- Additional safe offline parsers
- Formal JSON schemas and validation
- Duplicate-evidence handling
- Improved timeline normalization
- Report templates and analyst workflow tests

## Future
- Optional local database index
- Read-only investigation search
- Pluggable offline artifact parsers
- Reproducible packaged releases

Network exploitation, credential attacks, persistence, stealth, and indiscriminate scanning are intentionally out of scope.
