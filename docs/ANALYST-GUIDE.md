# Analyst Guide

CyberIQ DFIR Lab is local-first. Work on copies of evidence and retain the originals separately.

## Workflow
1. Create a case.
2. Add supplied evidence; the copied item is hashed with SHA-256.
3. Analyze saved text/logs offline.
4. Add analyst notes and update case status.
5. Review the case timeline.
6. Export JSON, Markdown, or HTML.
7. Generate a read-only HTML dashboard.

Observations produced by parsers are not automatically conclusions. Validate findings against the original evidence and document analyst reasoning.
